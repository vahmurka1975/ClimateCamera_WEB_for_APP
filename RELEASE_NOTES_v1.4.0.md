# ClimateCamera WEB for APP v1.4.0

Кандидат для стендовой проверки, только ESP32 + HTU21D/GY-21. Основа: https://github.com/vahmurka1975/ClimateCamera_WEB_for_APP. Другие репозитории не используются. Публикация в GitHub не выполнялась.

Добавлены страницы /admin и /setup; постоянный профиль сети и учётных записей в cc_device; поиск Wi-Fi; DHCP/статический IPv4; настройка резервной точки доступа; смена администратора и ограниченной учётной записи. Предусмотрены резервные копии продуктов, настроек либо обоих наборов и восстановление соответствующего содержимого. Копии настроек содержат пароли без шифрования.

Административные операции проверяют права на сервере. Для копирования, восстановления, сохранения параметров и сброса предусмотрены повторный ввод пароля администратора, токен и подтверждение. Есть сброс настроек с сохранением продуктов и полный сброс. Управляющие транзакции журналируются, продукты хранятся в двух банках с CRC. Это не заменяет испытания с прерыванием питания.

Первый переход требует USB-прошивки новой таблицы partitions_140.csv. Упаковка содержит отдельные bootloader.bin, partitions.bin, boot_app0.bin, firmware.bin. Не начинайте переход через обычное OTA. Резервная копия старых данных обязательна; реальная миграция не испытана. Детали: INSTALL_v1.4.0_RU.md.

Сборка PlatformIO esp32dev: espressif32 6.6.0, Arduino-ESP32 2.0.14, TFT_eSPI 2.5.43. Команда: `python -m platformio run -e esp32dev`. Пользовательский Secrets.h в комплект не включён; есть Secrets.example.h. В каталоге firmware — готовые файлы. MANIFEST.json, SHA256SUMS.txt и BUILD_REPORT.md описывают комплект и выполненные проверки.

Не проверено на устройстве: Wi-Fi/AP, права доступа в реальных HTTP-запросах, полный цикл backup/restore, сбросы, миграция старых данных, прерывание питания и безопасность реле. Компиляция и корректная структура BIN не означают готовность к эксплуатации без стендовых испытаний.
