# Release Notes — ClimateCamera v1.3.3 (HTU21D / GY-211)

## Ключевые изменения в версии 1.3.3

1. **Полноценное управление реле осушителя воздуха (`IN3`, `GPIO 14`) в непрерывном режиме:**
   * Канал `IN3` (`PIN_RELAY_IN3 = 14`, активный уровень `HIGH`) управляет осушителем воздуха.
   * Осушитель включается при превышении влажности над верхним порогом `curHum > humTarget + humHyst` и работает **непрерывно** до снижения влажности до целевой уставки `curHum <= humTarget`.

2. **Два независимых контура влажности (`IN2` Увлажнитель + `IN3` Осушитель) с взаимной блокировкой:**
   * Канал `IN2` (`GPIO 17`, Увлажнитель) работает в импульсном режиме (`20 с ВКЛ / 120 с пауза`) при `curHum < humTarget - humHyst` до достижения `curHum >= humTarget`.
   * Взаимная блокировка исключает одновременную работу увлажнителя и осушителя.
   * При отказе датчика `HTU21D (GY-211)` (3 ошибки чтения подряд или устаревание данных > 7 с), остановке системы или входе в режим Web OTA оба реле (`IN2` и `IN3`) гарантированно выключаются.

3. **Гибкая настройка комплектации (`humidEnabled` и `dehumEnabled`) с сохранением в NVS:**
   * В веб-интерфейсе («Настройки климата»), локальном меню энкодера (`УВЛАЖНИТЕЛЬ IN2`, `ОСУШИТЕЛЬ IN3`) и через Serial (`humen 0|1`, `dehen 0|1`) можно независимо разрешить или отключить каждый канал.
   * Настройки сохраняются в структуру `StoredConfig` (`52 байта`, ключ `cfg_v43` в NVS) с защитой `CRC-32` и полной обратной совместимостью с сохранёнными профилями от `v1.3.2` (по умолчанию при миграции: `humidEnabled = true`, `dehumEnabled = false`).

4. **Обновление экранов `ILI9341 320×240`, Web UI и документации `README.md`:**
   * На главном экране (`1/5`) и экране `ВЫХОДЫ РЕЛЕ` (`2/5`) отображаются все 4 канала: `ХОЛ (IN4)`, `УВЛ (IN2)`, `ОСУ (IN3)`, `ВЕН (IN1)`.
   * В карточке «Состояние оборудования» Web UI отображается живой статус `IN3 · Осушитель` (`ВКЛ`, `ВЫКЛ`, `Отключён`).
   * Все возможности версий `v1.3.2` и `v1.3.3` подробно документированы в `README.md`.
