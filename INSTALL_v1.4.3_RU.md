# Полная инструкция по установке и обновлению прошивки ClimateCamera v1.4.3 (`INSTALL_v1.4.3_RU.md`)

Данное руководство содержит пошаговые инструкции «для чайников» по установке и обновлению прошивки **ESP32 Climate Camera v1.4.3** на **Windows 10** всеми доступными способами:
1. **Через утилиту `esptool`** (с нуля: установка драйверов, Python, `esptool`, резервное копирование и прошивка готовыми `.bin`-файлами из командной строки).
2. **Через среду разработки `PlatformIO` (VS Code)** (с нуля: установка VS Code, плагина PlatformIO, настройка `platformio.ini`, сборка и прошивка в один клик).
3. **Через Arduino IDE 1.8.19 + `esptool`** (экспорт бинарного файла и запись с новой таблицей разделов).
4. **По воздуху (OTA через браузер)** (только при обновлении с версии **v1.4.2**, где уже установлена новая таблица разделов).

## 1. Важные правила перед началом (Прочитайте обязательно!)

Начиная с линейки **v1.4.2 / v1.4.3**, в прошивке используется новая таблица разделов Flash-памяти (`partitions_142.csv`), включающая выделенный двухбанковый раздел **`cc_store`** с защитой целостности CRC32 и транзакционным журналом для надёжного хранения продуктов и истории взвешиваний.

> ⚠️ **ГЛАВНОЕ ПРАВИЛО БЕЗОПАСНОСТИ ДАННЫХ:**
> Ни при каких обстоятельствах **НЕ выполняйте очистку всей памяти (`erase_flash`, `erase-flash`, `--erase-all`)** и не включайте в Arduino IDE пункт `Erase All Flash Before Sketch Upload: Enabled`, если на контроллере уже есть ваши настройки, список продуктов и история взвешиваний!

Почему это критически важно:
* На версиях **v1.3.3 и старше** продукты и настройки хранятся в разделе **NVS (`0x9000`)**.
* Когда вы прошиваете **v1.4.3** поверх **v1.3.3** без стирания Flash-памяти, при первом запуске новая прошивка автоматически обнаружит старую базу в NVS (`cc_prod`), проверит её и **перенесёт (мигрирует)** все продукты и историю взвешиваний в новый защищённый раздел `cc_store`.
* Если же выполнить `erase_flash`, вся память NVS сотрётся до того, как прошивка v1.4.3 сможет перенести ваши данные.

## 3. Подготовка Windows 10: установка драйвера USB-UART и поиск COM-порта

Этот шаг нужен как для `esptool`, так и для `PlatformIO`. Чтобы компьютер «увидел» плату ESP32 по USB-кабелю:

1. **Используйте кабель с передачей данных (Data USB).** Многие кабели от зарядок и повербанков имеют только 2 провода питания — от них на плате загорится светодиод, но компьютер плату не увидит.
2. **Откройте Диспетчер устройств Windows 10:**
   * Нажмите правой кнопкой мыши по кнопке **«Пуск»** (в левом нижнем углу экрана).
   * В появившемся меню выберите **«Диспетчер устройств»**.
3. Подключите плату ESP32 к USB-порту компьютера и найдите в списке раздел **«Порты (COM и LPT)»**:
   * Раскройте его стрелочкой слева.
   * Вы должны увидеть новую строку, например:
     * `Silicon Labs CP210x USB to UART Bridge (COM5)`
     * или `USB-SERIAL CH340 (COM5)`
     * или `USB-Enhanced-SERIAL CH9102 (COM5)`
   * Запомните номер порта в скобках (например, **`COM5`** — у вас может быть `COM3`, `COM4`, `COM7` и т.д.).
4. **Что делать, если раздела «Порты (COM и LPT)» нет или появилось «Неизвестное устройство» с жёлтым треугольником:**
   * Посмотрите на прямоугольную микросхему на плате ESP32 рядом с USB-разъёмом:
     * Если на ней написано **CP2102** (квадратная микросхема) — скачайте и установите драйвер **Silicon Labs CP210x Universal Windows Driver** с официального сайта Silicon Labs (`silabs.com/developers/usb-to-uart-bridge-vcp-drivers`). Распакуйте архив, нажмите правой кнопкой по файлу `silabser.inf` и выберите **«Установить»**.
     * Если написано **CH340G / CH340C** (прямоугольная с ножками по бокам) — скачайте и запустите установщик **`CH341SER.EXE`** с сайта производителя WCH (`wch-ic.com`).
     * Если написано **CH9102X** — установите драйвер **`CH343SER.EXE`** с сайта WCH.
   * После установки драйвера переподключите кабель USB и убедитесь, что порт `COM...` появился в Диспетчере устройств.

## 4. Способ 1. Прошивка через `esptool` на Windows 10 (Пошагово «для чайников»)

Утилита **`esptool`** — это официальная программа от компании Espressif (создателя микроконтроллеров ESP32) для чтения и записи памяти контроллера. Она работает на базе языка Python.

### 4.1. Установка Python 3 на Windows 10

Если у вас ещё не установлен Python, выполните следующие шаги:

1. Откройте браузер и перейдите на официальный сайт: **https://www.python.org/downloads/windows/**
2. Нажмите на большую жёлтую кнопку **«Download Python 3.12.x»** (или актуальную версию Python 3).
3. Запустите скачанный установочный файл `python-3.x.x-amd64.exe`.
4. ⚠️ **ОЧЕНЬ ВАЖНО!** На самом первом экране установщика **обязательно поставьте обе галочки внизу окна**:
   * `[v] Use admin privileges when installing py.exe`
   * `[v] Add python.exe to PATH` (Добавить Python в PATH)
   *(Если не поставить галочку «Add python.exe to PATH», Windows не будет знать команду `python` и `pip`!)*
5. Нажмите **«Install Now»** и дождитесь окончания установки.
6. В конце, если есть кнопка **«Disable path length limit»** (Отключить ограничение длины пути в 260 символов), нажмите на неё и подтвердите — это также очень поможет в будущем при работе с PlatformIO и Arduino.
7. Нажмите **«Close»**.

### 4.2. Установка `esptool`

1. Нажмите на клавиатуре сочетание клавиш **`Win + R`** (клавиша со значком Windows + латинская буква `R`).
2. В появившемся окошке «Выполнить» введите:
   ```text
   powershell
   ```
   и нажмите **Enter**. Откроется синее окно **Windows PowerShell**.
3. Скопируйте следующую команду, вставьте её в окно PowerShell (правой кнопкой мыши) и нажмите **Enter**:
   ```powershell
   py -m pip install --upgrade pip esptool
   ```
   *(Если команда `py` не сработала, введите: `python -m pip install --upgrade pip esptool`)*
4. Подождите 15–30 секунд, пока скачаются пакеты и в конце появится строка `Successfully installed esptool-...`.
5. Проверьте, что `esptool` установлен, выполнив команду:
   ```powershell
   py -m esptool version
   ```
   В ответ программа выведет свою версию (например, `esptool.py v4.7.0` или выше).

### 4.3. Подготовка файлов для прошивки

1. Создайте на диске `C:` простую папку без русских букв и пробелов, например:
   ```text
   C:\ESP32_Flash
   ```
2. Положите в эту папку `C:\ESP32_Flash` четыре бинарных файла комплекта **v1.4.3**:
   * `bootloader.bin` — загрузчик ESP32
   * `partitions.bin` — таблица разделов v1.4.2/v1.4.3 (включающая раздел `cc_store`)
   * `boot_app0.bin` — селектор активного OTA-раздела
   * `firmware.bin` — сама прошивка ClimateCamera v1.4.3

*(Примечание: если у вас есть только исходный код проекта, но ещё нет этих 4 файлов `.bin`, посмотрите **Раздел 5.8** или **Раздел 7**, как получить их при сборке).*

### 4.4. Как открыть командную строку / PowerShell в папке с файлами

Чтобы не вводить длинные пути к файлам вручную:
1. Откройте папку `C:\ESP32_Flash` в стандартном Проводнике Windows, где лежат ваши 4 файла `.bin`.
2. Щёлкните левой кнопкой мыши по **адресной строке Проводника** вверху окна (там, где написано `C:\ESP32_Flash`).
3. Сотрите текст в адресной строке, напишите туда слово:
   ```text
   powershell
   ```
   и нажмите клавишу **Enter**.
4. Откроется окно PowerShell, в котором в начале строки уже будет написано:
   ```text
   PS C:\ESP32_Flash>
   ```
   Это значит, что вы находитесь прямо в нужной папке!

### 4.5. Проверка связи с ESP32 и определение размера Flash-памяти

Подключите плату ESP32 к компьютеру. Допустим, в Диспетчере устройств она определилась как **`COM5`** (во всех командах ниже замените `COM5` на ваш реальный номер порта!).

Введите в окне PowerShell команду проверки памяти:
```powershell
py -m esptool --chip esp32 --port COM5 flash-id
```

* **Как должна ответить плата:**
  Вы увидите строки вида:
  ```text
  Chip is ESP32-D0WD-V3 (revision v3.0)
  Detected flash size: 4MB
  ```
* **Что делать, если на экране бегут точки `Connecting........_____.....` и программа выдаёт ошибку:**
  На некоторых платах ESP32 автосброс не срабатывает сам. В этом случае сделайте так:
  1. Введите команду в PowerShell и нажмите **Enter**.
  2. Как только на экране появилась надпись `Connecting....`, **зажмите и удерживайте пальцем кнопку `BOOT` (или `IO0`)** на плате ESP32.
  3. Не отпуская `BOOT`, коротко нажмите и отпустите вторую кнопку **`EN` (или `RST` / `RESET`)**.
  4. Когда в окне побежали строки подключения (`Chip is ESP32...`), отпустите кнопку `BOOT`.

### 4.6. Снятие полной резервной копии памяти ESP32 (Бэкап)

Перед любым обновлением настоятельно рекомендуется сохранить полный слепок текущей памяти ESP32 в файл на компьютер. Если что-то пойдёт не так, вы сможете за 1 минуту вернуть контроллер ровно в то состояние, в котором он был до прошивки (вместе со всеми продуктами, историей и настройками!).

* **Если в шаге 4.5 определилось `Detected flash size: 4MB` (4 мегабайта — стандарт большинства плат):**
  Выполните команду:
  ```powershell
  py -m esptool --chip esp32 --port COM5 --baud 460800 read-flash 0x000000 0x400000 backup_full_4MB.bin
  ```
* **Если в шаге 4.5 определилось `Detected flash size: 8MB` (8 мегабайт):**
  Выполните команду:
  ```powershell
  py -m esptool --chip esp32 --port COM5 --baud 460800 read-flash 0x000000 0x800000 backup_full_8MB.bin
  ```

*(Примечание: если ваша версия `esptool` ругается на дефис в `read-flash`, напишите через нижнее подчёркивание: `read_flash`).*
Чтение займёт около 40–60 секунд. В папке `C:\ESP32_Flash` появится файл `backup_full_4MB.bin` — сохраните его в надёжное место.

### 4.7. Запись прошивки v1.4.3 через `esptool`

Выберите ваш вариант:

#### Вариант А. Переход со старых версий (v1.3.3 и старше) на v1.4.3 ИЛИ прошивка новой платы
Требуется записать все 4 файла по их точным адресам. Скопируйте и выполните в PowerShell одну общую команду (не забыв заменить `COM5` на ваш порт):

```powershell
py -m esptool --chip esp32 --port COM5 --baud 460800 write-flash 0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware.bin
```

Если на высокой скорости (`460800`) возникают ошибки записи, выполните ту же команду на стандартной надёжной скорости **`115200`**:

```powershell
py -m esptool --chip esp32 --port COM5 --baud 115200 write-flash 0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware.bin
```

*(Для более старых версий `esptool` используйте `write_flash` вместо `write-flash`)*:
```powershell
py -m esptool --chip esp32 --port COM5 --baud 115200 write_flash 0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware.bin
```

Что делает эта команда:
* `0x1000 bootloader.bin` — записывает загрузчик;
* `0x8000 partitions.bin` — записывает новую таблицу разделов с разделом `cc_store`;
* `0xe000 boot_app0.bin` — указывает запускать прошивку из первого раздела `app0`;
* `0x10000 firmware.bin` — записывает саму прошивку v1.4.3;
* При этом область **`0x9000` (NVS)** НЕ затрагивается и НЕ стирается! Все ваши настройки и продукты сохраняются и при первом старте автоматически перенесутся в `cc_store`.

#### Вариант Б. Обновление с версии v1.4.2 на v1.4.3 по кабелю
Если у вас уже стояла версия **v1.4.2** (с уже прошитой новой таблицей разделов), достаточно прошить только `boot_app0.bin` и `firmware.bin` (или все 4 файла из Варианта А — это тоже абсолютно безопасно, так как раздел `cc_store` они не задевают):

```powershell
py -m esptool --chip esp32 --port COM5 --baud 460800 write-flash 0xe000 boot_app0.bin 0x10000 firmware.bin
```

Когда запись дойдёт до `100%` и появится надпись:
```text
Hash of data verified.
Leaving...
Hard resetting via RTS pin...
```
прошивка успешно завершена!

### 4.8. Частые ошибки `esptool` и их решение

1. **`PermissionError(13, 'Отказано в доступе')` или `could not open port 'COM5'`:**
   * Порт `COM5` сейчас занят другой программой (открыт Монитор порта в Arduino IDE, PlatformIO, PuTTY и т.д.). Закройте все остальные программы и повторите команду.
2. **`A fatal error occurred: Failed to connect to ESP32: Timed out waiting for packet header`:**
   * Плата не перешла в режим загрузки автоматически. Запустите команду и при появлении `Connecting....` зажмите кнопку **`BOOT`** на плате на 2–3 секунды, пока не начнётся запись.
   * Также проверьте, не подключены ли к пинам `GPIO 0`, `GPIO 2` или `GPIO 12` внешние цепи, мешающие старту загрузчика.
3. **`No such file or directory: 'bootloader.bin'`:**
   * Окно PowerShell открыто не в той папке, где лежат файлы `.bin`. Перейдите в нужную папку командой:
     ```powershell
     cd C:\ESP32_Flash
     ```
4. **Как восстановить старую прошивку из бэкапа (если что-то пошло не так):**
   * Выполните запись сохранённого образа обратно с адреса `0x000000`:
     ```powershell
     py -m esptool --chip esp32 --port COM5 --baud 460800 write-flash 0x000000 backup_full_4MB.bin
     ```

## 5. Способ 2. Полная инструкция по прошивке через PlatformIO на Windows 10

**PlatformIO** — это профессиональная среда разработки для микроконтроллеров на базе редактора **Visual Studio Code**.
Главное преимущество PlatformIO для проекта ClimateCamera v1.4.3:
* Он **сам скачивает** нужную версию ядра ESP32 и библиотеку дисплея `TFT_eSPI`.
* Он **сам применяет** настройки пинов экрана `User_Setup.h` (вам не нужно вручную копировать файлы в папки библиотек!).
* Он **сам компилирует и прошивает** новую таблицу разделов `partitions_142.csv`, загрузчик и прошивку нажатием одной кнопки **Upload**, сохраняя ваши данные в NVS и `cc_store`.

### 5.1. Установка Visual Studio Code (VS Code)

1. Перейдите на официальный сайт: **https://code.visualstudio.com/**
2. Нажмите кнопку **«Download for Windows»** и запустите скачанный файл `VSCodeUserSetup-x64-...exe`.
3. При установке на шаге «Выберите дополнительные задачи» поставьте галочки:
   * `[v] Добавить действие "Открыть с помощью Code" в контекстное меню проводника`
   * `[v] Добавить в PATH (требуется перезагрузка)`
4. Завершите установку и запустите **Visual Studio Code**.

### 5.2. Установка расширения PlatformIO IDE

1. В открывшемся окне VS Code посмотрите на левую вертикальную панель значков и нажмите на иконку **«Extensions» (Расширения)** — она выглядит как четыре квадратика (или нажмите сочетание клавиш **`Ctrl + Shift + X`**).
2. В строке поиска сверху введите:
   ```text
   PlatformIO IDE
   ```
3. Выберите первый результат **PlatformIO IDE** (с логотипом оранжевой головы муравья/инопланетянина от `platformio.org`) и нажмите синюю кнопку **«Install»**.
4. **Дождитесь полной установки!**
   * В правом нижнем углу VS Code появится уведомление: `PlatformIO Installer: Installing PlatformIO Core...`.
   * Установка при первом запуске скачивает встроенный Python и инструменты сборки — это занимает **от 3 до 10 минут** в зависимости от скорости интернета.
   * **Не закрывайте VS Code**, пока в правом нижнем углу не появится сообщение об успешном завершении установки и кнопка **«Reload Now»** (Перезагрузить).
5. Нажмите **«Reload Now»** (или закройте и заново откройте VS Code). На левой панели появится значок головы муравья (PlatformIO), а в самой нижней синей полосе экрана (Status Bar) появятся значки управления: домик, галочка (`✓`), стрелочка (`→`), мусорная корзина и штекер.

### 5.3. Правильная распаковка и подготовка проекта

> ⚠️ **КРИТИЧЕСКИ ВАЖНО ДЛЯ WINDOWS 10:**
> В пути к папке проекта **НЕ должно быть русских букв (кириллицы) и пробелов**!
> Например, если имя вашего пользователя в Windows написано по-русски (`C:\Users\Иван\Рабочий стол\...`), компилятор ESP32 при сборке выдаст ошибку.

Поэтому сделайте так:
1. Создайте в корне диска `C:` папку `C:\ESP32Projects`.
2. Распакуйте архив с прошивкой в неё так, чтобы путь к проекту выглядел, например, вот так:
   ```text
   C:\ESP32Projects\ClimateCamera_1_4_3_IDE1819
   ```
3. Убедитесь, что прямо внутри этой папки (`C:\ESP32Projects\ClimateCamera_1_4_3_IDE1819`) находятся:
   * файл `platformio.ini`
   * файл таблицы разделов `partitions_142.csv`
   * папка с исходным кодом `ClimateCamera_1_4_3_IDE1819/` (или `src/`)
   * папка `TFT_eSPI_setup/User_Setup.h`

### 5.4. Настройка файла `Secrets.h` и проверка `platformio.ini`

1. Зайдите в подпапку с исходниками (`C:\ESP32Projects\ClimateCamera_1_4_3_IDE1819\ClimateCamera_1_4_3_IDE1819`).
2. Проверьте наличие файла **`Secrets.h`**:
   * Если там есть только `Secrets.example.h`, скопируйте его в этой же папке и переименуйте копию в **`Secrets.h`**.
   * Откройте `Secrets.h` блокнотом или в VS Code и проверьте настройки вашей сети Wi-Fi (`WIFI_SSID`, `WIFI_PASSWORD`), статического IP и паролей по умолчанию (если на плате уже были сохранены настройки в NVS от прошлой версии, камера автоматически возьмёт их из NVS).
3. Проверьте файл **`platformio.ini`** в корневой папке проекта. Для версии **v1.4.3** он должен выглядеть следующим образом:

```ini
[platformio]
src_dir = ClimateCamera_1_4_3_IDE1819

[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino

; Скорость монитора порта и прошивки
monitor_speed = 115200
upload_speed = 460800

; Подключение таблицы разделов v1.4.2 / v1.4.3 с разделом cc_store
board_build.partitions = partitions_142.csv

; Автоматическая загрузка библиотеки дисплея
lib_deps =
    bodmer/TFT_eSPI @ ^2.5.43

; Автоматическое подключение конфигурации дисплея 2.4" ILI9341 без ручного редактирования библиотеки
build_flags =
    -D USER_SETUP_LOADED=1
    -include TFT_eSPI_setup/User_Setup.h
```

4. Проверьте, что в корне проекта рядом с `platformio.ini` лежит файл **`partitions_142.csv`** со следующим содержимым (стандарт для 4 МБ и 8 МБ Flash):

```csv
# Name,   Type, SubType, Offset,  Size,     Flags
nvs,      data, nvs,     0x9000,  0x5000,
otadata,  data, ota,     0xe000,  0x2000,
app0,     app,  ota_0,   0x10000, 0x1E0000,
app1,     app,  ota_1,   0x1F0000,0x1E0000,
cc_store, data, 0x99,    0x3D0000,0x20000,
spiffs,   data, spiffs,  0x3F0000,0x10000,
```

### 5.5. Открытие проекта и первая компиляция (Build)

1. В VS Code в верхнем меню нажмите **«File» → «Open Folder...»** (Файл → Открыть папку...).
2. Выберите корневую папку проекта:
   ```text
   C:\ESP32Projects\ClimateCamera_1_4_3_IDE1819
   ```
   *(именно ту папку, в которой лежит файл `platformio.ini`!)* и нажмите **«Выбор папки»**.
3. Если появится окно «Do you trust the authors of the files in this folder?», поставьте галочку и нажмите **«Yes, I trust the authors»**.
4. Подождите 1–3 минуты, пока PlatformIO проиндексирует проект (в правом нижнем углу будет надпись `PlatformIO: Configuring project...`).
5. **Запустите проверочную сборку (Build):**
   * На самой нижней панели окна VS Code нажмите на значок **галочки (`✓`)** (`PlatformIO: Build`).
   * *(Альтернативный способ: нажмите на значок муравья на левой панели → раскройте `PROJECT TASKS` → `esp32dev` → `General` → нажмите **`Build`**).*
6. Внизу откроется окно терминала. При самой первой сборке PlatformIO автоматически скачает пакет `espressif32`, компилятор и библиотеку `TFT_eSPI`.
7. Дождитесь завершения сборки. В конце лога должна появиться зелёная надпись:
   ```text
   ========================= [SUCCESS] Took XX.XX seconds =========================
   ```

### 5.6. Загрузка прошивки в ESP32 через PlatformIO (Upload)

1. Подключите плату ESP32 к компьютеру по USB.
2. По умолчанию PlatformIO сам находит нужный COM-порт. Если к компьютеру подключено несколько COM-устройств, вы можете нажать на значок вилки/штекера с номером порта (`Auto` / `COM5`) в нижней панели VS Code и выбрать порт вашей ESP32.
3. Нажмите на значок **стрелочки вправо (`→`)** (`PlatformIO: Upload`) в нижней панели VS Code (или выберите `PROJECT TASKS` → `esp32dev` → `General` → **`Upload`**).
4. PlatformIO скомпилирует проект и запустит запись всех разделов (`bootloader.bin`, `partitions.bin`, `boot_app0.bin` и `firmware.bin`) в плату ESP32:
   * Если в терминале побежали точки `Connecting........_____`, зажмите кнопку **`BOOT`** на плате ESP32 на 2 секунды, пока не пойдут проценты записи (`Writing at 0x00010000... (10 %)`).
5. Когда вы увидите:
   ```text
   Hash of data verified.
   Leaving...
   Hard resetting via RTS pin...
   ========================= [SUCCESS] Took XX.XX seconds =========================
   ```
   прошивка **v1.4.3** успешно установлена!

> ⚠️ **ВАЖНО:** Никогда не нажимайте в меню PlatformIO (`Platform` → `Erase Flash`), если хотите сохранить свои продукты и настройки! Кнопка обычной загрузки (**`Upload`**) не стирает раздел NVS и раздел `cc_store`.

### 5.7. Проверка работы и логов через Serial Monitor в PlatformIO

Сразу после прошивки вы можете посмотреть диагностический лог запуска камеры:
1. Нажмите на значок **штекера (вилки)** (`PlatformIO: Serial Monitor`) на нижней панели VS Code.
2. В терминале откроется монитор порта на скорости `115200`.
3. Нажмите кнопку **`EN` (`RST`)** на плате ESP32, чтобы увидеть лог с самого начала загрузки:
   * Камера выведет версию прошивки `v1.4.3`.
   * Выведет статус хранилища продуктов (`cc_store`) и результат миграции из NVS (если производился переход с `v1.3.3`).
   * Выведет IP-адрес, полученный по Wi-Fi или заданный статически.

### 5.8. Где взять `.bin`-файлы после сборки в PlatformIO

После того как вы нажали **Build** в PlatformIO, все готовые бинарные файлы автоматически создаются в скрытой папке `.pio` внутри вашего проекта:
```text
C:\ESP32Projects\ClimateCamera_1_4_3_IDE1819\.pio\build\esp32dev\
```
Там находятся:
* `bootloader.bin`
* `partitions.bin`
* `firmware.bin`

А файл `boot_app0.bin` лежит в стандартной папке пакетов PlatformIO по адресу:
```text
C:\Users\<ИМЯ_ПОЛЬЗОВАТЕЛЯ>\.platformio\packages\framework-arduinoespressif32\tools\partitions\boot_app0.bin
```
Вы можете скопировать эти 4 файла для прошивки других плат через `esptool` или использовать `firmware.bin` для последующих обновлений по воздуху (OTA).

### 5.9. Частые ошибки PlatformIO на Windows 10 и их решение

1. **Ошибка при нажатии Upload: `could not open port 'COM5': PermissionError(13, 'Отказано в доступе')`:**
   * У вас осталась открытой вкладка `Serial Monitor` внизу экрана. Нажмите на значок корзины в правом верхнем углу окна терминала, чтобы закрыть монитор порта, и снова нажмите `Upload`.
2. **Ошибка при сборке: `Fatal error: TFT_eSPI_setup/User_Setup.h: No such file or directory`:**
   * Вы открыли в VS Code не корневую папку проекта, а внутреннюю подпапку. Откройте через `File → Open Folder` именно ту папку, где лежит `platformio.ini` и папка `TFT_eSPI_setup`.
3. **Если загрузка обрывается на середине (`Timed out waiting for packet header` во время записи):**
   * В файле `platformio.ini` измените строку `upload_speed = 460800` на `upload_speed = 115200`, сохраните файл (`Ctrl + S`) и нажмите `Upload` ещё раз.

## 6. Способ 3. Обновление по воздуху (OTA) при переходе с v1.4.2 на v1.4.3

Если на вашей климатической камере **уже установлена версия v1.4.2** (то есть таблица разделов с `cc_store` уже записана в память ранее), подключать камеру к компьютеру по USB не обязательно:

1. Откройте веб-интерфейс камеры в браузере и войдите под учётной записью **`admin`**.
2. Перейдите в раздел **«Администрирование»**.
3. **Сделайте резервную копию:** нажмите кнопку скачивания полной резервной копии (`.ccbackup`) и сохраните файл на компьютер.
4. В блоке **«Обновление прошивки (OTA)»** выберите файл **`firmware.bin`** версии **v1.4.3**.
5. Нажмите **«Загрузить и обновить»** и дождитесь автоматической перезагрузки контроллера (1–2 минуты).
6. Обновите страницу в браузере (`Ctrl + F5`) и убедитесь, что в шапке отображается версия **`v1.4.3`**.

## 8. Проверка камеры после установки v1.4.3 (Чек-лист)

После успешной прошивки и перезагрузки ESP32 выполните быструю проверку:

1. **Проверьте экран камеры:**
   * На дисплее должна отображаться версия **`v1.4.3`**, показания температуры/влажности, статус исполнительных устройств и корректное время.
2. **Проверьте веб-интерфейс и сохранность данных:**
   * Откройте IP-адрес камеры в браузере (и нажмите **`Ctrl + F5`** для обновления кэша страницы).
   * Убедитесь, что список ваших продуктов и история взвешиваний на месте.
3. **Проверьте диагностику хранилища `cc_store`:**
   * Откройте в браузере страницу `http://<IP-адрес-камеры>/api/status` (или вкладку «Администрирование»).
   * Проверьте значения диагностических полей версии **v1.4.3**:
     * `"fwVersion": "1.4.3"`
     * `"productsStoreState"`: должно быть `"ok"` (или `"migrated"` сразу после перехода с `v1.3.3`).
     * `"bank0Valid": true`, `"bank1Valid": true` — оба банка памяти синхронизированы и прошли проверку CRC32.
     * `"migrationDone": true` — миграция завершена.
     * `"pendingTransaction": false` — нет незавершённых транзакций.
     * `"lastWriteOk": true`, `"lastWriteError": ""` — ошибок записи нет.
4. **Выполните тестовое сохранение и скачайте свежий бэкап:**
   * Добавьте тестовое взвешивание или проверьте карточку продукта, перезагрузите камеру и убедитесь, что данные сохраняются.
   * В разделе «Администрирование» нажмите кнопку создания полной резервной копии — скачается проверенный файл вида **`ClimateCamera_1.4.3_full.ccbackup`**.
